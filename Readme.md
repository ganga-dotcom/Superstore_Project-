# Superstore Business Intelligence Dashboard | Power BI

## Project Overview
The Superstore Business Intelligence Dashboard is a data analytics project developed using Microsoft Power BI. The objective is to analyze sales, profit, product performance, customer behavior, and regional business performance using interactive dashboards.

The project uses the Superstore dataset as its primary data source to transform raw sales data into meaningful business insights and support data-driven decision-making.

## Project Objectives
- Analyze overall sales, profit, and quantity.
- Identify top 5 and bottom 3 performing products.
- Analyze category-wise and sub-category-wise sales.
- Compare regional sales and profitability.
- Understand customer purchasing behavior.
- Monitor sales trends over time.
